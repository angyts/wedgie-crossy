Cars now retain colors by computing their original spawn column from current column and traffic phase (including screen wrap). Rivers alternate log-only and lily-only: row 12 logs, row 36 lilies, row 60 logs, etc. Lily-only rivers have a stationary safe pad at column 5; the bank cells in that column are guaranteed free of trees by the existing row generator. Logs and pads are never mixed in the same river row. The deterministic log-only river still requires timing to cross. Test both types and the color stability on the Wedgie before further gameplay additions.
