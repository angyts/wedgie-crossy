# River prototype

Adds blue river bands at rows 12, 36, ...; deterministic three-cell logs; support checking on entry; one-cell carry at traffic phase changes; unsupported-water death; off-screen carry death; and a four-frame splash animation. Off-screen carry has a short extra pre-splash hold. This is a first discrete-grid river prototype, not yet full swept physics. DEV_MODE remains enabled. Verify on physical hardware before extending rivers or adding trains. The game-over message is currently shared with road crashes and should be customized after hardware verification.
