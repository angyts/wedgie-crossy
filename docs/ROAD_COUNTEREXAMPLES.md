# Road counterexample diagnostics

The offline road inspection records complete row signatures and each
failing (boundary index, hazard phase, reason) triple. A bounded
caller-provided matrix supports comparing up to 16 traffic geometries.
Phase-cap violations raise rather than silently passing.

This report does not prove that a passing case is fair. The existing
whole-join screen does not expose a per-phase failure list, and the
successor audit uses provisional physics, finite horizons, and
conservative all-state continuation requirements. The runtime approved
generator remains grass-only.
