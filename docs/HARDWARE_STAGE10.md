# Stage 10 — simplified HUD and four-way facing

Remove progress bar, pause hint, BEST highlight, x10 label. Keep a short yellow bold score at ten-row milestones. Chicken now has distinct left/right/up (back)/down (front) sprites. Pause shows colored red and green squares beside RESUME and NEW RUN, rather than A/B text. Controls remain Y to open pause, B to resume, A to start a new run while paused. The firmware's palette approximates requested red/green; confirm physical colors on device.

The hardware-verified scrolling baseline is retained in git history. This stage requires hardware verification before being considered production-ready.
