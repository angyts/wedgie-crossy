Experimental half-tile visual preview for moving cars and logs on traffic updates. SMOOTH_TRAFFIC=True enables one extra LCD.show per moving tick; set False to restore prior rendering immediately. Logical collision masks and traffic phase are unchanged. Preview skips the player's log row, and omits edge-crossing sprites rather than clipping them; visual artifacts and low FPS are possible. It is not full pixel interpolation and not a collision-swept renderer. Validate tests and hardware performance before treating as production-ready.
